## Research references

The program search in this project follows FunSearch. EoH and ReEvo informed the use of short explanations alongside candidate code in the enhanced prompt.

- Romera-Paredes et al., Nature. [Mathematical discoveries from program search with large language models](https://doi.org/10.1038/s41586-023-06924-6)
- Liu et al., ICML 2024. [Evolution of Heuristics](https://proceedings.mlr.press/v235/liu24bs.html)
- Ye et al., NeurIPS 2024. [ReEvo](https://proceedings.neurips.cc/paper_files/paper/2024/hash/4ced59d480e07d290b6f29fc8798f195-Abstract.html)

## OR3 benchmark

The OR3 evaluation uses item sequences extracted from the official FunSearch notebook. This repository ships the download and extraction scripts. The scripts check the notebook's SHA-256 before extracting the sequences. [Reproduction steps](README.md#data-and-optional-final-benchmark-replication), [upstream notebook](https://github.com/google-deepmind/funsearch/blob/main/bin_packing/bin_packing.ipynb), [OR-Library description](https://people.brunel.ac.uk/~mastjjb/jeb/orlib/binpackinfo.html)

方向性假设（观察项，不计入通过/失败）：单行记忆是否改变探索分布

尺度上可判定为没有转化为分数。

#### 测量说明（分类器的盲区）

标准 1 按分类器判定为不通过，但分类器对 basic 模式代码有已知
盲区：最好候选 #31 的比率带思想是用 `(r-item)/r` 的除法表达的，
没有触发 `ratio` 标志（该标志要求残差与含 item 的表达式直接
比较），所以被归入兜底的 `plain` 家族。`plain` 10 次里包含了
结构上不同的机制（死区惩罚、比率带、mod 奖励等，见生成器机制
清单），家族数 8 低估了真实的机制多样性。但预注册标准写的是
分类器口径，判定仍按分类器执行，此处仅披露测量局限。

#### 初步解读

与 B 组（v4/v5：多样性上升）相反，C 组的记忆让搜索更集中：
家族数 9→8，头号占比持平 43.5%，只是头号家族从 `mod` 换成
`plain`。单行记忆 + basic 模式下，生成器围绕最好家族反复
精修（#17 死区惩罚 265.267 及其四次精修、#27–#31 比率带精修），
多样性没有打开。质量上最好成绩 265.133 优于 v3 的 265.200，
但未达到预注册的 265.100；validation 267.7 略差于 v3 的 267.6。

#### 初步解读

与 C 组（集中但温和）不同，A 组的记忆造成了**严重集中**：
家族数 26→5，头号占比 12.5%→75%。机制：运行早期一个
`scaled+triangular` 候选拿到 265.167 成为最好家族，记忆行
全程说“精修它”，生成器照做 24 次（V 形罚的各种变体：幅度
扫描、中心移动、折扣、对称翻转）。v5 的“精修最好家族”语义
在 basic 模式下被执行得过于彻底——生成器没有 Strategy 文本
可供推理替代方案，单行记忆成了主要指导，于是深度开发一个
家族 24 次。避让清单未能阻止：`scaled`（3 次，265.267）与
`dist+scaled+triangular`（3 次，265.267）虽被避让，但
`scaled+triangular` 是另一个精确签名，不在避让之列。
r1 部分轮（27 次已评估，最好 265.133）反而优于 r2，但 r1
不完整，不能作为校准结果；重启丢掉更好部分轮的损失如实记录。

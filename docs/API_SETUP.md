# API 设置与预算边界

默认 `--provider offline` 使用人工样例，不访问网络，不收费。增强组的人工说明只检查输出格式，不能证明 Prompt 有效。

真实预实验于 2026-11-06 完成 16 次 DeepSeek 请求，返回模型别名 `deepseek-flash`。
服务端未证实不可变底层版本，不能把 `expected_model_version` 当作实测信息。
`configs/formal-api.example.json` 是关闭状态的正式配置模板，待模型配置、当前定价与预算确定后填写。
其中 null 是有意阻止误调用，不应为了跑通而随意填入数值。

## 先明确调用范围

旧接口预实验获批最多 16 次、10 元，16 次额度已经用完。`run_authorized_pilot.py` 不是下一轮通用启动器。
不要删除、清空或换账本绕过旧限制。新增调用需要确定范围，并保留旧花费及未知预留的累计记录。
正式比较的四组×种子数×每次调用数需有足够请求额度，超出预算会停止，不能当成完整比较。

已提供保留原账本的 128 次补充校准入口，见 [运行说明](CALIBRATION_20261107.md)。
它默认不收费，只在用户执行明确授权参数后增加请求额度，原累计金额上限保持 10 元。

## 私有配置与密钥

新配置可复制模板为 `configs/formal.local.json`，已加入 Git 忽略规则；不覆盖已有私有配置。
配置只保存密钥环境变量名 `FUNPACK_API_KEY`，不能写真实密钥。
正式入口 `formal.py run` 支持终端隐藏输入，结束时清除由它临时设置的密钥。
亦可在本地安全地设置环境变量，不能把值发到聊天、截图、代码或日志。

不发送请求的预检：

```powershell
python scripts/check_api.py --config configs/formal.local.json
```

预检只检查配置与环境变量存在性，缺少密钥会报错但不打印密钥。
实际调用必须同时满足启用配置、显式 `--allow-paid`、有效密钥、持久账本和已确定的费用/请求上限。
正式操作顺序见 `FORMAL_PROTOCOL.md`。

## 费用和失败怎么记录

- API 请求每次最多尝试一次，无自动重试；失败也计入请求次数。
- SQLite 账本跨进程保留请求与费用，断电/未知用量保留预留，不自动退款式清零。
- 响应原文、实际模型字段、用量和完成原因保存在每次运行日志；所有提示与可执行候选一同记录。
- 按输入/输出 token 单价估算，未假定缓存折扣，不能代替平台实际账单。
- 私有 API 配置、账本、原始付费日志默认不上传。公开实验材料前应单独检查并整理可复现证据。

历史 CNY 预实验示例中的价格是 2026-10-29 配置记录，并非当前报价。
实际启用前查官方文档 https://api-docs.deepseek.com/zh-cn/quick_start/pricing/ ，记录核验日期和币种。
